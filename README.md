# 🚀 Featured Project

## 📟 Smart Gas Meter Reading System

An end-to-end AI-powered gas meter reading system.

### Features

- 🔹 Custom YOLOv8 model for meter detection
- 🔹 Custom PaddleOCR model trained on gas meter digits
- 🔹 OpenCV preprocessing pipeline
- 🔹 Automatic meter reading
- 🔹 CSV output generation
- 🔹 High-accuracy digit recognition

**Technologies Used**

- Python
- YOLOv8
- PaddleOCR
- TensorFlow
- OpenCV
- NumPy
- Pandas
